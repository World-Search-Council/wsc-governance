## 🏛️ Core Constitutional Documents

This repository houses the formal constitutional, ethical, operational, and judicial treaties governing the World Search Council and all accredited practitioners:

| Document | Live Portal Enforcement | Description |
| :--- | :--- | :--- |
| **[`Founding_Charter.md`](Founding_Charter.md)** | [`/standards`](https://www.worldsearchcouncil.org/standards) | Constitutional treaty establishing the WSC mission, General Assembly, Technical Steering bodies, and 5 Working Groups (`WG-01..WG-05`). |
| **[`CODE_OF_ETHICS.md`](CODE_OF_ETHICS.md)** | [`/directory`](https://www.worldsearchcouncil.org/directory) | Binding ethical obligations for search transparency, user privacy protection, honest AI/GEO representation, and client data ownership. |
| **[`Code_of_Operations.md`](Code_of_Operations.md)** | [`/verify`](https://www.worldsearchcouncil.org/verify) | Operational rules including the **WSC Transfer Protocol (WTP)** (§1.1–§1.2) — guaranteeing zero agency vendor lock-in via SHA-256 attested exit handoff packages. |
| **[`Code_of_Arbitration_Dispute_Resolution.md`](Code_of_Arbitration_Dispute_Resolution.md)** | [`/arbitration`](https://www.worldsearchcouncil.org/arbitration) | Procedural rules of the **WSC Penalty Arbitration Tribunal** (`ARB-YYYY-XXXX` dockets, 14-day respondent defense window, conflict recusal, and Level 1–3 credential sanctions). |
